# Subur.in Backend

Backend service untuk proyek **Subur.in**.

## Tech Stack

- Node.js
- Express.js
- MongoDB (opsional, sesuai konfigurasi)

## Cara Menjalankan

1. Install dependencies:
   ```bash
   npm install
   ```
2. Jalankan server:
   ```bash
   npm run dev
   ```
